# 3-Minute Demo Guide

### 0:00–0:30 — Problem
“Civil infrastructure can be affected by earthquakes, wind, floods, corrosion, fatigue and thermal effects. Periodic inspection can miss changes between inspections. Our goal is continuous AI-based risk monitoring and early warning.”

### 0:30–1:15 — Architecture
“CNN extracts local patterns from sensor signals, LSTM learns how those patterns evolve over time, and a Genetic Algorithm is intended to optimize key hyperparameters. The output is hazard classification, risk severity and an alert.”

### 1:15–2:15 — Live dashboard
Show the sensor cards, move the slider, point out the predicted hazard and risk level, then choose a high-risk point to trigger the warning.

### 2:15–3:00 — Validation and innovation
“This is an MVP demonstration using synthetic sensor data and a lightweight baseline so the demo is dependable. We are deliberately not claiming unverified performance numbers. The next validation stage will train/test CNN-LSTM-GA on a traceable structural dataset using accuracy, precision, recall, F1, RMSE/MAE, false-alarm rate and inference latency.”
